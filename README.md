# Gráfica de la evolución tecnológica histórica

Viaje interactivo por la evolución tecnológica de la humanidad: **130 hitos**, desde el dominio del fuego (c. 400.000 a.C.) hasta el año 10¹⁰⁰.

- **La curva**: la altura es el número de inventos acumulados y el eje horizontal es el tiempo, con la misma escala comprimida para pasado y futuro. Plana durante 400.000 años; hoy, vertical.
- **Viaje animado** con ilustraciones por hito, zoom libre (pellizcar / rueda), minimapa y ritmo de descubrimientos (de 1 invento cada 132.000 años a 8,5 al año).
- **Futuro** con hojas de ruta reales a corto plazo (fusión, cuántica, longevidad, espacio, astronomía) y proyecciones etiquetadas por grado de certeza.
- **Datos**: 11 indicadores reales en escala de tiempo real (población, esperanza de vida, pobreza extrema, alfabetización, riqueza mundial, energía, precio solar, transistores, usuarios de Internet, coste del genoma y cómputo de IA), más la escalera del cómputo.

Es un único `index.html` sin build: React 18, htm y Lucide desde CDN.

## Ejecutar

Abre `index.html` en el navegador. Publicado con GitHub Pages: https://emiliojimenezmartin.github.io/grafica-de-evolucion-de-la-humanidad/

> Las fechas futuras son estimaciones y escenarios, no predicciones.
